# Splunk SIEM Log Analysis – SSH Attack Detection

## Project Overview

This project demonstrates how a Security Operations Center (SOC) analyst can detect and investigate suspicious activity using a Security Information and Event Management (SIEM) platform.

In this lab, a simulated attacker machine attempted multiple SSH login attempts against an Ubuntu server. Authentication logs from the server were ingested into Splunk Enterprise, where searches were performed to identify and analyze the attack activity.

This project demonstrates skills in:

- SIEM log analysis
- Security monitoring
- Threat detection
- Linux log investigation
- Splunk Search Processing Language (SPL)

# Step 3 – Simulate SSH Attack

From the Kali Linux attacker machine, SSH login attempts were made using invalid credentials.

Example command:

```
ssh fakeuser@192.168.56.102
```

This generated authentication failures on the Ubuntu server.

![Kali SSH Attack](3-kali-ssh-attack.png)

---

# Step 4 – Verify Logs on Ubuntu

The failed login attempts were confirmed in the system authentication logs.

Log file:

```
/var/log/auth.log
```

Example log entry:

```
Failed password for invalid user fakeuser from 192.168.56.101 port 40336 ssh2
```

![Auth Log Failed Login](4-auth-log-failed-login.png)

---

# Step 5 – Splunk SIEM Dashboard

Splunk Enterprise was used as the SIEM platform to ingest and analyze the authentication logs.

![Splunk Dashboard](5-splunk-dashboard.png)

---

# Step 6 – Identify SSH Attack Events

Splunk search query used to identify failed SSH login attempts:

```
index=auth source="/var/log/auth.log" "Failed password"
```

This query returned multiple authentication failures generated by the simulated attacker.

![Splunk SSH Events](6-splunk-ssh-attack-events.png)

---

# Step 7 – Analyze Attack Activity

To summarize the attack activity, the following query was used:

```
index=auth source="/var/log/auth.log" "Failed password"
| stats count by host, source
```

This query aggregates authentication failures and highlights the affected system.

![Detection Query](7-splunk-detection-query.png)

# Investigation Summary

The SIEM investigation successfully identified a simulated SSH brute-force login attempt against the Ubuntu server.

Key findings:

- Multiple failed login attempts were recorded
- Logs were successfully ingested into Splunk
- SPL queries identified authentication failures
- Attack activity was confirmed through log analysis
